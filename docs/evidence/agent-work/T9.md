# T9: rutas de delegación gestionadas (parcial)

R `86855193f4` añadió una captura interna del solicitante desde el turno admitido del host. Vincula agente, clave de sesión, instancia y run; distingue remitentes y generaciones de sesión, y conserva las comprobaciones de autoridad y política de herramientas. La prueba `managed-task.turn.test.ts` falló antes del cambio porque aceptaba una identidad sin turno o con permiso revocado; después pasó 5/5. También pasaron `pnpm tsgo:core`, lint focalizado y hooks.

Esta capacidad todavía no está conectada a una herramienta pública ni a un emisor de admisión. No se marca ningún caso de cobertura de `coverage.json` como certificado. Faltan `agents_routing`, `delegation_bypass`, `hook_is_observation`, la integración de host y las pruebas de gateway.

R `9a6a7e311b` añadió el registro de tarea con autoridad revalidada en la transacción y antes del commit, junto con un parser estricto del encargo. La regresión falló antes: un permiso revocado dejaba `revoked-submit` en el almacén. Ahora el registro rechazado deja cero filas; también se rechazan campos de continuación ajenos al contrato. Pasaron 25/25 pruebas focalizadas de registro, admisión y manejo, tipos, lint y hooks. El token del productor sigue siendo un dato privado del almacén; ninguna herramienta para el modelo está conectada aún.

R `a38a766b16` añadió las herramientas internas `managed_tasks_submit` y `managed_tasks_inspect`, aún sin ensamblarlas en el runtime productivo. Registran un presupuesto finito desde configuración del host, devuelven solo el ID y leen únicamente dentro de la instancia de sesión capturada. La prueba focalizada pasó 2/2: mismo ID tras otro turno, otro remitente sin acceso, token privado ausente de la salida, sesión reemplazada rechazada y entrada mal formada sin fila. Pasaron además tipos, lint, formato y hooks. Faltan `admit`, `resolve`, `cancel`, informe del productor y el enlace con las herramientas reales.

R `0bbb8cebeb` añadió `managed_tasks_admit` a esa fábrica interna. Obtiene destino y referencia de `inspect` autenticado, exige bytes con el digest guardado, reserva el presupuesto y pasa `ManagedSpawnAdmission` a `spawnSubagentDirect` con clave estable, colector silencioso y timeout finito del host. La prueba del borde de herramienta pasó 4/4: un replay del mismo reclamo devuelve `needs-reconciliation` sin segundo despacho y un brief cambiado se rechaza antes de reservar o lanzar. La batería focalizada de almacén, admisión, pipeline y herramienta pasó 24/24 antes del último caso; tipos, lint y hooks pasaron. La herramienta aún no está ensamblada en el runtime, el lanzador está sustituido en esta prueba de borde y falta una prueba de gateway real.

R `2b14dfbf81` añadió `managed_tasks_resolve` y `managed_tasks_cancel` a la fábrica interna. Ambos revalidan la autoridad en la transacción y antes del commit; la regresión anterior guardaba una decisión tras revocar el turno. Pasaron 11/11 pruebas de manejo y 5/5 de la herramienta: un remitente ajeno no consume, el mismo recibo recupera el mismo hijo y cancelar al padre marca al descendiente. Pasaron tipos, lint, formato y hooks. Sigue pendiente conectar el informe autenticado del productor y ensamblar estas herramientas en el gateway con política y perfil medidos.

R `63cdfa6c1e` añadió `managed_tasks_report` como fábrica interna para el productor nativo. El modelo entrega solo el resultado; el worker deriva la tarea del run persistido y exige la misma sesión, agente, generación y admisión confirmada. Una revocación antes del commit revierte la escritura. La prueba con SQLite real cubrió informe válido, recibo repetido, run ajeno, generación sustituida, revocación y resultado inválido. Pasaron 25/25 pruebas focalizadas, `tsgo:core`, lint, formato y hooks. Falta montar la herramienta en el runtime y probar el gateway extremo a extremo.

La prueba de ensamblaje rechaza otro run y otra sesión; pasaron 39/39 pruebas focalizadas de informe, sesión y herramientas de gateway, además de tipos, lint y hooks.
