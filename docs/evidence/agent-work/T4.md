# T4: presupuesto del proveedor (parcial)

R `9347938830329154ad30a7bb0b102ebd9817cfda` certifica la ruta HTTP nativa de OpenAI Responses para encargos gestionados. El transporte reserva presupuesto sobre los bytes del cuerpo final antes de cada envío, incluidos los reintentos del SDK. Mantiene el límite de salida exigido y rechaza WebSocket, redirecciones, compaction y destinos que no corresponden al endpoint certificado. Los errores de transporte dejan la causa durable `transport-unavailable`. La ruta previa de OpenAI Completions permanece cubierta.

La prueba `managed-task.provider-stream.test.ts` pasó 14/14. Incluye liquidación de uso de Responses, bloqueo de un reintento sin recuperación disponible antes del segundo HTTP y espera durable al caer la conexión. La prueba `server.managed-task-requester.e2e.test.ts` pasó 1/1 sobre un Gateway autenticado: `ingenieria` registra y admite una revisión para `adversary`; el hijo realiza una llamada de modelo, persiste `review.v1` y termina sin una llamada adicional.
