# B6: certificar opencode Go para encargos

David lo pidió el 2026-10-10 ("ok pues hay que hacerlo") para poder abrir la parte B de T12. Hasta R `f1c5f34`, solo podía recibir un encargo un trabajador que llamara al proveedor `openai` en `api.openai.com`, y ningún agente de la Mini lo usa.

## Qué cambia en R (`19c2ed1`, rama `feat/agent-work-integration`, sin push)

- **La certificación es por servidor y API, no por nombre de proveedor.** El nombre es un alias que pone el operador. Lo que se certifica es a dónde va la petición y cómo se mide (`CERTIFIED_ENDPOINTS` en `managed-task.provider-stream.ts`):
  - `https://api.openai.com/v1`, con Chat Completions y Responses, como antes;
  - `https://opencode.ai/zen/go/v1`, solo con Responses.
- **Por qué solo Responses en opencode.** Responses se reserva sobre el cuerpo exacto que sale por la red (`responsesDispatchHook`) y se liquida con el uso del evento final, sin depender de opciones del modelo. La ruta Chat Completions de opencode solo manda `include_usage` cuando la fila del modelo lo declara, y sin uso cada llamada quedaría por conciliar.
- **El plugin sigue sin certificar.** El proveedor que se llama literalmente `opencode-go` pasa por su plugin (`wrapStreamFn`), y la guarda de `attempt-stream-settle.ts` lo rechaza igual que antes. Los alias sin plugin (`opencode-go-resp`, `opencode-go-resp-2`) sí pasan.
- **Hueco cerrado: un encargo que cae a un CLI o a un plugin.** Antes, si el modelo de un encargo fallaba, el agente pasaba a su siguiente fallback, y si ese corría por CLI (claude-cli) o por un plugin (el app-server de codex) gastaba sin reservar nada. Ahora:
  - `runCliAgentInternal` (`cli-runner.ts`) rechaza un encargo antes de preparar el CLI ("Managed CLI runtime is not budget-certified"). Cubre el primario, los fallbacks y la compactación por CLI.
  - `runAgentHarnessAttempt` (`harness/selection.ts`) rechaza un plugin dentro de un encargo ("Managed plugin harness is not budget-certified").
  - Las dos guardas consultan la base solo si la sesión es de subagente, porque todo encargo corre como subagente (`mintSpawnSessionKey` con `backend: "subagent"`).

## Pruebas en R

- `managed-task.provider-stream.test.ts`:
  - "rejects uncertified provider routes" agrega los casos de opencode que se parecen y no son: sin `/v1`, otro puerto, `http`, otro dominio, usuario y clave, query, y Chat Completions;
  - "charges an opencode Go Responses call on its wire body and settles cached usage" pasa la llamada por un servidor local que responde como opencode. Comprueba la ruta `/zen/go/v1/responses`, que la reserva sea igual a los bytes del cuerpo y que el uso se liquide con la caché (120 de entrada, 100 de caché, 7 de salida).
- `cli-runner.managed-budget.test.ts` (nuevo): con encargo, rechaza sin preparar el CLI. Sin encargo, el CLI corre. En una sesión que no es de subagente, ni siquiera consulta la base.
- `harness/selection.test.ts`, "refuses a plugin harness for a managed run before it can call its own model": con encargo, rechaza sin correr el plugin. Sin encargo, el plugin corre.
- Mutaciones, cada una roja con la regla o la guarda vieja: la regla `f1c5f34` falla las dos pruebas de certificación; sin la guarda de CLI falla `cli-runner.managed-budget`; sin la del plugin falla la prueba de `selection`.

## Delegación desde un encargo

El panel de VEREDICTO-B6-r1 sostuvo que un trabajador de encargo puede lanzar subagentes con `sessions_spawn` y que esos corren sin reserva. No es así. `sessions_spawn` y `sessions_send` rechazan la llamada cuando el turno que llama es de un encargo ("Managed task delegation requires a child contract", `sessions-spawn-tool.ts:383-388` y `sessions-send-tool.ts:151-156`, con prueba en `sessions-managed-delegation.test.ts`). `spawnSubagentDirect` solo se llama desde esas dos herramientas y desde la admisión de encargos, y un encargo nuevo trae su propio presupuesto.

## Lo que no cubre

- Los agentes con primario `opencode-go/deepseek-v4.1-flash` (`adversary`, `operaciones`, `reviewer`, `verifier`, `scout`) siguen sin poder recibir un encargo (fila B5/T12 de `followups.md`). La ruta `ingenieria → adversary` no se abre; `operaciones → ingenieria` sí puede, porque el trabajador es `ingenieria`.
- `maxContextTokens` sigue en `null`. La Mini registra los tamaños desde las 05:14Z del 2026-10-10, y la admisión no se abre hasta medirlo.

## Script de actualización

El que cita `T12-runbook.md` para pasar la Mini de `f1c5f34` a `19c2ed1`. Va en este documento porque la guarda de la matriz no deja agregar scripts después del par.

```bash
#!/bin/bash
# B6: actualiza la Mac Mini de R f1c5f34 a R 19c2ed1 (certifica opencode Go con Responses y cierra el gasto
# por CLI o plugin dentro de un encargo). La admisión sigue cerrada. Corre en la Mac de desarrollo: copia los
# paquetes por scp y actúa en la Mini por ssh. Los dos builds usan el esquema 27, así que volver atrás es
# reinstalar f1c5f34; la base no se restaura. Salida: ACTUALIZADO OK, PARO (nada tocado) o REVERSA.
set -uo pipefail
H=gon@100.73.187.5
A=~/.local/state/encargos-loop/artifacts
D=$A/T12
LOG=$D/actualizar-19c2ed1-$(date -u +%Y%m%dT%H%M%SZ).log
mkdir -p "$D"
{
  echo "== $(date -u +%T) copiar paquetes"
  ssh -o ConnectTimeout=10 "$H" 'mkdir -p /tmp/r19 /tmp/rf1' &&
    scp -q "$A/paquete-19c2ed1/openclaw-2026.9.7.tgz" "$A/paquete-19c2ed1/openclaw-ai-2026.9.7.tgz" "$H:/tmp/r19/" &&
    scp -q "$A/paquete-f1c5f34/openclaw-2026.9.7.tgz" "$A/paquete-f1c5f34/openclaw-ai-2026.9.7.tgz" "$H:/tmp/rf1/" ||
    { echo "PARO: no se pudieron copiar los paquetes (no se tocó nada)"; exit 1; }
  ssh -o ConnectTimeout=10 "$H" 'bash -s' <<'REMOTO'
set -uo pipefail
OC=~/.openclaw
export PATH=$OC/tools/node/bin:/usr/bin:/bin:/usr/sbin:/sbin
BIN=$OC/bin/openclaw
NPM=$OC/tools/node/bin/npm
LABEL=ai.openclaw.gateway
DOM=gui/$(id -u)
PLIST=~/Library/LaunchAgents/$LABEL.plist
SHA_NEW=69de612d28c77dabdf62c214cd5e49247d5c5c8af8e926b75e460e3251e3d2b4
SHA_OLD=76c0883e2a8f6206ed63dc78b291effbfa6946cf9d4bcc646ae9b88365982e2c
SHA_AI=0512fd870a86f40ea06f13931ef36a9ca9af07286d378fb1e717453ba6ffbcc8
F=$OC/respaldos/pre-19c2ed1-$(date +%Y%m%d-%H%M)

paso() { echo "== $(date -u +%T) $*"; }
paro() { echo "PARO: $* (no se tocó nada)"; exit 1; }
acotado() { perl -e 'alarm shift; exec @ARGV' "$@"; }
gw_pid() { launchctl print "$DOM/$LABEL" 2>/dev/null | awk '$1 == "pid" {print $3}'; }
crons_on() { acotado 60 "$BIN" cron list --json 2>/dev/null | python3 -c '
import json, sys
d = json.load(sys.stdin); jobs = d.get("jobs", d) if isinstance(d, dict) else d
print(" ".join(sorted(j["id"] for j in jobs if j.get("enabled"))))'; }
running() { acotado 60 "$BIN" cron list --json 2>/dev/null | python3 -c '
import json, sys
d = json.load(sys.stdin); jobs = d.get("jobs", d) if isinstance(d, dict) else d
print(sum(1 for j in jobs if (j.get("state") or {}).get("runningAtMs")))'; }
hash_ok() { [ "$(shasum -a 256 "$1" | cut -d' ' -f1)" = "$2" ]; }

detener() {
  local pid; pid=$(gw_pid)
  launchctl bootout "$DOM/$LABEL" 2>&1 || true
  for _ in $(seq 60); do
    [ -z "$pid" ] || ! kill -0 "$pid" 2>/dev/null && break
    sleep 1
  done
  if [ -n "$pid" ] && kill -0 "$pid" 2>/dev/null; then echo "no salió en 60 s: SIGKILL a $pid"; kill -9 "$pid"; sleep 2; fi
  for _ in $(seq 30); do lsof -nP -iTCP:18789 -sTCP:LISTEN >/dev/null 2>&1 || return 0; sleep 1; done
  echo "el puerto 18789 sigue ocupado:"; lsof -nP -iTCP:18789 -sTCP:LISTEN; return 1
}

arrancar() {
  launchctl bootstrap "$DOM" "$PLIST" 2>&1 || true
  for _ in $(seq 60); do
    acotado 20 "$BIN" health --json > /tmp/t12-health.json 2>/dev/null && return 0
    sleep 5
  done
  return 1
}

instalar() { "$NPM" install -g --allow-scripts="$1/openclaw-2026.9.7.tgz" "$1/openclaw-ai-2026.9.7.tgz" "$1/openclaw-2026.9.7.tgz" 2>&1 | tail -3; }

reversa() {
  paso "REVERSA: $*"
  if ! detener; then echo "REVERSA PARADA: el gateway no se detuvo; no reinstalo nada"; exit 2; fi
  instalar /tmp/rf1
  "$BIN" --version
  if arrancar; then echo "REVERSA OK: el gateway volvió a f1c5f34"; else echo "REVERSA INCOMPLETA: el gateway no responde; foto en $F"; fi
  exit 2
}

paso "0. Revisar antes de tocar nada"
v=$("$BIN" --version); echo "$v"; [[ "$v" == *"(f1c5f34)"* ]] || paro "la versión viva es $v, no f1c5f34"
[ -f "$PLIST" ] || paro "no existe $PLIST"
hash_ok /tmp/r19/openclaw-2026.9.7.tgz "$SHA_NEW" || paro "hash de /tmp/r19/openclaw-2026.9.7.tgz"
hash_ok /tmp/rf1/openclaw-2026.9.7.tgz "$SHA_OLD" || paro "hash de /tmp/rf1/openclaw-2026.9.7.tgz"
hash_ok /tmp/r19/openclaw-ai-2026.9.7.tgz "$SHA_AI" || paro "hash de /tmp/r19/openclaw-ai-2026.9.7.tgz"
hash_ok /tmp/rf1/openclaw-ai-2026.9.7.tgz "$SHA_AI" || paro "hash de /tmp/rf1/openclaw-ai-2026.9.7.tgz"
n=$(running); [ "$n" = "0" ] || paro "hay $n crons corriendo; repetir en unos minutos"
ANTES=$(crons_on); [ -n "$ANTES" ] || paro "no pude leer los crons habilitados"
echo "crons habilitados: $(wc -w <<< "$ANTES")"

paso "1. Detener el gateway"
detener || paro "el gateway no se detuvo; revisar a mano, puede estar abajo"

paso "2. Foto (seguro adicional; el esquema no cambia)"
mkdir -p "$F" && chmod 700 "$OC/respaldos" "$F"
sqlite3 "$OC/state/openclaw.sqlite" ".backup $F/openclaw.sqlite" || { arrancar; paro "falló la foto"; }
for f in "$OC"/agents/*/agent/openclaw-agent.sqlite; do
  id=$(basename "$(dirname "$(dirname "$f")")")
  sqlite3 "$f" ".backup $F/agent-$id.sqlite" || { arrancar; paro "falló la foto de $id"; }
done
cp -p "$OC/openclaw.json" "$F/" && chmod 600 "$F"/*
chk=$(sqlite3 "$F/openclaw.sqlite" "PRAGMA user_version; PRAGMA quick_check;" | tr '\n' ' ')
echo "foto $F: $chk, $(du -sh "$F" | cut -f1)"
[ "$chk" = "27 ok " ] || { arrancar; paro "la foto no es 27/ok: $chk"; }

paso "3. Instalar 19c2ed1"
instalar /tmp/r19
v=$("$BIN" --version); echo "$v"; [[ "$v" == *"(19c2ed1)"* ]] || reversa "la versión instalada es $v"

paso "4. Arrancar"
arrancar || reversa "el gateway no respondió health en 5 min"
echo "health ok"

paso "5. Comprobar"
grep -q 19c2ed1 "$OC/tools/node-v24.19.0/lib/node_modules/openclaw/dist/build-info.json" || reversa "build-info no es 19c2ed1"
echo "build-info: $(tr -d '\n ' < "$OC/tools/node-v24.19.0/lib/node_modules/openclaw/dist/build-info.json")"
echo "esquema: $(sqlite3 "file:$OC/state/openclaw.sqlite?mode=ro" 'PRAGMA user_version;')"
acotado 60 "$BIN" gateway call config.get --params '{}' --json 2>/dev/null | python3 -c '
import json, sys
d = json.load(sys.stdin); c = d.get("config", d)
m = c.get("managedTasks") if isinstance(c, dict) else None
print("managedTasks:", json.dumps(m))
sys.exit(0 if not m or not m.get("enabled") else 1)' || echo "AVISO: managedTasks habilitado; congelarlo (runbook 1.5)"
DESPUES=$(crons_on)
[ "$ANTES" = "$DESPUES" ] && echo "crons habilitados: los mismos $(wc -w <<< "$DESPUES")" || echo "AVISO: cambiaron los crons habilitados"
echo "ACTUALIZADO OK: R 19c2ed1 instalado con la admisión cerrada. Foto: $F"
REMOTO
} 2>&1 | tee "$LOG"
echo "log: $LOG"
```
