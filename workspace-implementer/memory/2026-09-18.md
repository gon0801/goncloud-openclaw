## Incidente: pre-commit exporta GIT_DIR y los tests git escapan al repo real
- El hook de pre-commit corre la batería con `GIT_DIR=<repo-real>`, `GIT_INDEX_FILE=<índice-real>`, `GIT_PREFIX=` vacío y `PRE_COMMIT=1` en el ambiente (verificado con `ps -E -p <pid-run-checks>`).
- Consecuencia: un test que hace `git -C $TMPREPO add -A` IGNORA el `-C` (GIT_DIR absoluto manda) y escribe en el índice real; con `-A` borra del índice todo lo que no existe en el tmp (índice quedó en 16 archivos) y `git update-ref refs/remotes/origin/main HEAD` MOVIÓ `origin/main` a mi commit. Se restauró con `git fetch origin main` + `git read-tree HEAD`.
- Regla: todo script de prueba que use git debe empezar con `unset GIT_DIR GIT_WORK_TREE GIT_INDEX_FILE GIT_PREFIX` (+ `GIT_AUTHOR_*`/`GIT_COMMITTER_*` si commitea). Puesto como guardia en `scripts/run-checks.sh` (protección global), en `corrida/preflight.sh` y en `test-corrida-preflight.sh`. <!-- project: github.com/gon0801/goncloud-openclaw -->
- El test de preflight ahora arma su propio repo temporal con ref local `origin/main` en vez de depender de `origin/*` del checkout (en CI de PR esos refs no siempre resuelven igual). <!-- project: github.com/gon0801/goncloud-openclaw -->

## Canal exec Mac: comandos largos mueren (COMPANION_APP_UNAVAILABLE)
- Todo comando de >~30s (sleep 45, git commit con hook de ~20min) tumba el canal; el proceso muere con él salvo que vaya despegado.
- Patrón: `nohup <cmd> >log 2>&1 & echo pid=$!`, luego sondear el log con comandos cortos. Nunca `sleep` largo dentro del comando.
- El `PATH` del exec es mínimo: faltan `/opt/homebrew/bin` (`node`, `timeout`, `gh`). El hook hereda el PATH → batería local en rojo por ambiente. Al commitear, exportar `PATH=/opt/homebrew/bin:...`.

## Stash compartido entre worktrees: no hacer stash/pop a la ligera
- `refs/stash` es global al repo; un `git stash pop` en un worktree puede aplicar el stash de otra rama (me pasó: trajo cambios ajenos + conflicto UU). Recuperación: mover untracked ajenos a /tmp (mv, reversible), `git checkout HEAD -- <paths>` para tracked, verificar diff vacío.
- Para demos "rojo" reversibles usar `mv` del archivo impl, nunca stash.

## Tests portables Mac/Linux
- `stat -f` en Linux NO falla (es stat de filesystem) → el fallback `|| stat -c` nunca corre. Usar helper con `uname`: `stat -f %Lp` en Darwin, `stat -c %a` en Linux.
- `exec -a NAME` funciona en bash de Linux (CI) para simular procesos detectables por `pgrep -f`.
